# BananaUtil

Small library for **Hats Reinvented** on Minecraft 26.1.2 (NeoForge):

- Tabula (`.tbl`) model reading and baking into vanilla `ModelPart`s
- `HeadLocator`: finds the head of any entity model (vanilla or modded) and the top of the skull, no per-mob data needed
- `ModelCapture`: records the boxes an entity renderer draws, to animate or redraw them
- GUI entity rendering and easing helpers
